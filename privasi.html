Kebijakan privasi

Berlaku sejak 23 November 2026 untuk aplikasi OAuth "rclone" yang dipakai pemiliknya sendiri.

Data yang diakses

File dan informasi file di Google Drive milik pemilik aplikasi, hanya untuk menyimpan, menampilkan, mengunduh, mengubah, dan menghapus file atas perintah pemilik.

Penyimpanan dan pembagian

Data berpindah langsung antara komputer pemilik dan Google. Token akses disimpan di komputer pemilik. Tidak ada server perantara milik aplikasi ini. Data tidak dijual, tidak dibagikan kepada pihak lain, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model AI.

Penggunaan informasi dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Mencabut akses

Akses bisa dicabut kapan saja di myaccount.google.com/permissions. Token di komputer dihapus dengan menghapus konfigurasi rclone.
